# 원본 검색 품질과 선택적 확장 기준

현재 검색은 로컬 SQLite FTS5를 사용하며 외부 모델 호출이나 임베딩 다운로드가 없습니다. 우선 모든 검색어가 일치하는 문서를 찾습니다. 없을 때만 절반 이상의 용어가 겹치는 **부분 일치 후보**를 제시하고 `match_mode: partial_terms`로 표시합니다. 파일명, 본문 일치 수, 수정 시각으로 순서를 정합니다. 검색 결과는 답변의 근거가 아니며 반드시 `read_local_artifact(id)`로 원본을 확인합니다.

2026-09-29 합성 문서 3개로 측정한 결과:

| 검색어 | 첫 후보 | 방식 |
|---|---|---|
| `ExampleCo 견적서` | `ExampleCo_견적서.txt` | 모든 용어 |
| `ExampleCo 견적서 교육 횟수` | `ExampleCo_견적서.txt` | 부분 일치. 원문에는 “교육 3회” |
| `ExampleCo 견적서 구축 범위` | `ExampleCo_견적서.txt` | 모든 용어 |
| `ExampleCo 교육` | `ExampleCo_견적서.txt` | 모든 용어. 다른 고객 교육 문서보다 우선 |
| `없는회사 고유자료` | 없음 | 일치 없음 |

이 작은 합성 시험은 실제 문서 전체의 정확도를 증명하지 않습니다. 부분 일치는 관련 없는 후보를 포함할 수 있고, 한국어 동의어·의미 변형까지 이해하지는 못합니다. 운영 문서에서 질문·정답 파일 쌍을 최소 20건 모아 상위 5개 후보의 적중률과 원본 읽기 성공률을 먼저 측정하세요. 반복되는 **의미 차이 때문에** 적중률이 부족할 때만 로컬 임베딩/재정렬기를 선택 기능으로 검토합니다. 모델 다운로드·디스크 사용량·재색인 비용을 명시하고 기본 설치에는 포함하지 않습니다. 비밀정보 필터나 허용 경로를 완화해 적중률을 높이지 않습니다.
